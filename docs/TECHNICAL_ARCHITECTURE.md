# Техническая архитектура

## Стек

Игра использует HTML5, CSS3, Vanilla JavaScript, Canvas 2D, Web Audio API, HTMLAudioElement и localStorage. Сборщик, фреймворк, сервер приложений и внешние runtime-зависимости не требуются.

## Точки входа

- `index.html` — Canvas и DOM-экраны меню/настроек.
- `styles/main.css` — адаптивный контейнер и DOM-интерфейс.
- `src/main.js` — состояние, ввод, физика, звук, отрисовка и игровой цикл.

## Машина состояний

| Состояние | Назначение |
|---|---|
| `levelIntro` | заставка уровня, таймер остановлен |
| `ready` | ведение мяча и ожидание ввода |
| `aim` | движение маркера по шкале |
| `flight` | полёт к корзине |
| `swish` | прохождение через кольцо |
| `bounce` | физика промаха |
| `result` | короткий переход |
| `over` | итоговый экран |

`requestAnimationFrame` вызывает `update(dt)` и `draw()`. `dt` ограничен 33 мс, чтобы возвращение на вкладку не вызывало скачка физики.

## Порядок отрисовки

1. фон площадки;
2. табло;
3. точка игрока;
4. след;
5. мяч;
6. HUD;
7. модальные игровые экраны.

## Canvas

`ResizeObserver` отслеживает CSS-размер. Буфер умножается на ограниченный `devicePixelRatio`, после чего контекст получает соответствующую матрицу. Это сохраняет чёткость и предотвращает растягивание мяча.

## Хранилище

- `basket888-best` — рекорд;
- `basket888-sound` — состояние звука;
- `basket888-language` — язык.

## Расширение

Новая механика должна иметь данные в `state`, обновление в `update`, визуализацию в `draw`/`hud`, явные переходы состояний и сброс полей в `reset`.
