# Ассеты и звук

## Финальные изображения

- `assets/court-rooftop.png` — площадка;
- `assets/ball-premium.png` — мяч;
- `assets/menu/main-menu.webp` — главное меню;
- `assets/menu/settings-menu.webp` — настройки;
- `assets/ui/scoreboard-panel-v2.png` — табло.

В production-ветки добавляются только финальные изображения. Chroma-key исходники и промежуточные генерации не публикуются.

## Аудио

| Файл | Событие |
|---|---|
| `menu-music.mp3` | меню и настройки |
| `dribble-hit.mp3` | касание паркета |
| `net-swish-v3.mp3` | попадание |
| `net-swish-v2.mp3` | промах |
| `shot-clock-buzzer.mp3` | окончание времени |
| `level-cheer.mp3` | заставка уровня |

Короткие эффекты воспроизводятся клонированием `HTMLAudioElement`; музыка меню использует один зацикленный экземпляр. Автовоспроизведение начинается только после пользовательского жеста из-за политики браузеров.

Перед добавлением аудио рекомендуется удалить тишину, применить fade-in/out, нормализовать громкость, ограничить пики и экспортировать MP3 44.1 kHz, 128–160 kbps.
