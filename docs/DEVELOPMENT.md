# Запуск и тестирование

## Локальный запуск

```bash
cd "/path/to/888"
python3 -m http.server 8080
```

Открыть `http://localhost:8080`.

## Проверка JavaScript

```bash
node --check src/main.js
```

После изменения ассетов выполнить жёсткое обновление: `Cmd+Shift+R` или `Ctrl+Shift+R`.

## Ручной QA

- меню и музыка запускаются после касания;
- настройки сохраняются после перезагрузки;
- заставка уровня останавливает таймер;
- отсчёт начинается с 24 секунд;
- сирена звучит при нуле;
- новый уровень не наследует старую анимацию;
- зона сужается каждый уровень и движется с уровня 4;
- дальность влияет на сложность;
- мяч круглый на разных viewport;
- попадание и промах звучат различно;
- второе касание паркета становится новой позицией;
- RU/EN тексты помещаются в интерфейс;
- игра работает в Chrome и Safari.

## Производительность

Не создавать изображения внутри кадра, переиспользовать `Image`, ограничивать массив следа, не выполнять DOM-операции в игровом цикле и контролировать размер растровых ассетов.
